# Обработка и анализ медицинских изображений

## Описание проекта

Проект направлен на **разработку и исследование алгоритмов обработки и анализа медицинских изображений кожи**, а также создание **веб-сервиса для автоматической классификации изображений**.  
В качестве основы используется открытый датасет **HAM10000 (ISIC 2018)**, содержащий 10 015 дерматоскопических фотографий кожных новообразований 7 классов.

Финальная модель — **Vision Transformer ViT-B/16** со специальным порогом для меланомы (порог 0.14 повышает чувствительность с 47% до 79%).

**Цели проекта:**

- Изучить современные подходы к классификации медицинских изображений.
- Реализовать и сравнить модели машинного и глубокого обучения.
- Разработать веб-сервис, который принимает изображение на вход и возвращает прогноз модели.

## Этапы и план работы

### **Этап 1. Постановка задачи и выбор подходов**

- Определение целей, метрик и архитектуры системы.
- Анализ датасетов ISIC-2018 и HAM10000.
- Выбор технологий (PyTorch, FastAPI, Streamlit, MLflow, Docker).
- Подготовка плана экспериментов и схемы архитектуры.

**Результат:** схема архитектуры системы, план работы.

---

### **Этап 2. Сбор данных и EDA**

- Скачивание и очистка данных.
- Предобработка изображений (224×224).
- Анализ распределений по классам, визуализация.
- Разработка базовых аугментаций (flip, rotation, crop и др.).

**Инструменты:** Python, pandas, matplotlib, seaborn, OpenCV, Albumentations.  
**Результат:** чистый датасет и отчёт EDA.

---

### **Этап 3. ML бейзлайны**

- Извлечение признаков через замороженный ResNet-18 (512-мерные эмбеддинги).
- Сравнение классических моделей: LogisticRegression (Macro F1 = 0.548), KNN (0.524).
- DL бейзлайн: ResNet-18 frozen (Macro F1 = 0.571) - лучший из классических.
- Выбор метрики: **Macro F1** (из-за дисбаланса классов).

**Результат:** `ML_checkpoint3.ipynb`, таблица сравнения моделей.

---

### **Этап 4. Улучшение моделей и эксперименты**

**Обнаружение и исправление утечки данных (data leakage):**  
Датасет HAM10000 содержит несколько снимков одного образования. При случайном сплите снимки одного образования оказывались и в train, и в test, из-за чего метрики были завышены ~на 10%. Исправлено: сплит по `lesion_id` (`src/make_splits.py`).

**Сравнение 6 DL-архитектур** (после исправления утечки):

| Модель              | Val Macro F1 | Val Accuracy |
| ------------------- | ------------ | ------------ |
| **ViT-B/16**        | **0.664**    | **0.768**    |
| ResNet-18 fine-tune | 0.635        | 0.751        |
| EfficientNet-B0     | 0.570        | 0.716        |
| MobileNetV2         | 0.526        | 0.701        |

**Порог меланомы:** без порога модель пропускала 53% меланом. Порог P(mel) ≥ 0.14 поднял чувствительность с 47% до 79% (`src/threshold_tuning.py`).

**Результат:** `ML_checkpoint5.ipynb`, `ML_checkpoint6.ipynb`, финальная модель ViT-B/16.

## Как запустить

### Требования

- Python 3.11+
- Файл `service/artifacts/model.pth`

### Backend (FastAPI)

```bash
pip install -r service/requirements.txt

uvicorn service.app.main:app --host 0.0.0.0 --port 8000 --reload
```

Сервер доступен по адресу `http://localhost:8000`

**Эндпоинты:**

- `POST /forward` - анализ изображения (хедеры: `x-top-k`, `x-mode: global|windows`)
- `GET /model-info` - информация о модели (архитектура, классы, метрики)
- `GET /history` - история всех запросов
- `GET /stats` - статистика времени обработки
- `GET /health` - статус сервиса

### Frontend (Streamlit)

```bash
pip install -r frontend/requirements.txt

streamlit run frontend/streamlit_app.py
```

Интерфейс доступен по адресу `http://localhost:8501`

### MLflow (просмотр экспериментов)

```bash
pip install mlflow

mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000
```

Эксперимент: `skin_lesion_isic2018`, лучший run: `vit_b16_final`, стадия модели: `PRD`.

### Docker

```bash
docker build -f service/Dockerfile -t skin-service .

docker run -p 8000:8000 skin-service
```

### Где лежит модель

Файл `service/artifacts/model.pth` можно скачать из Kaggle Dataset команды или Google Drive.  
После скачивания положить в `service/artifacts/model.pth`.

## Как работает инференс

### Global mode (`x-mode: global`)

Изображение масштабируется до 224×224 и подаётся в ViT-B/16 целиком. Быстрый режим по умолчанию.

### Windows mode (`x-mode: windows`)

Изображение разбивается на перекрывающиеся фрагменты 224×224 пикселей с шагом 112. Каждый фрагмент прогоняется через модель, вероятности усредняются. Лучше подходит для крупных или детализированных снимков.

### Порог меланомы

Если вероятность класса `mel` ≥ 0.14, модель предсказывает меланому, даже если другой класс технически вероятнее. Это повышает чувствительность (recall) с 47% до 79%, что критично для медицинского скрининга.

## Ограничения модели

- Модель обучена только на датасете HAM10000 - не тестировалась на других популяциях и оборудовании.
- Macro F1 на тесте = 0.580 - в реальном применении возможны ошибки.
- Наиболее частые путаницы: меланома ↔ кератоз (mel↔bkl, 25%), меланома ↔ родинка (mel↔nv, 15%).
- Сервис является **исследовательским прототипом** и не предназначен для медицинской диагностики.
- Не тестировалась на мобильных дерматоскопах и фото со смартфона.
